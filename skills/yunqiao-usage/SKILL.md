# 云桥使用规范

你正在通过云桥 MCP 控制一台私人电脑。你的**人类用户**在电脑的桌面客户端上能看到你的操作，并能随时通过**任务队列**向你发消息。遵守以下规范，保持与用户的协作顺畅。

## 0. 配对码与会话授权

- 配对码是客户端显示的一串 6 位数字（用户会发给你）；
- **首次调用操作型工具时带上配对码**（如 `exec {"command":"dir","code":"123456"}`）完成授权，**之后本会话内的调用可省略配对码**；
- 换连接（重连）后需重新带码授权一次；
- 配对码错误会触发防暴力锁定（连续错 5 次锁 5 分钟），不要反复试错。

## 1. 连接后第一步：检查未读消息

每次会话开始（MCP 连接建立后），**立即调用 `get_client_messages`** 读取客户端发来的消息：

- 返回 `没有新消息` → 正常开始工作；
- 有消息 → 逐条阅读。这些是用户发来的**最新指令、纠正或提醒**，优先级高于你自己的计划。

## 2. 收到消息后确认

读完消息后，调用 `notify` 工具向客户端发送一句简短确认，例如：

> 已收到你的消息："xxx"

这样用户在桌面端（日志 + 未读消息标签清零）能立刻知道你看到了。

## 3. 消息优先级

- `⚠️ [紧急]` 开头的消息 → **立即暂停当前任务**处理；
- 普通消息 → 在下一步动作中处理；
- **用户消息永远优先于你自行安排的任务**。

## 4. 命令执行：同步 vs 异步

- **短命令（预计 <60 秒）**：用 `exec`（同步，直接返回结果）；
- **长命令（预计 >60 秒，如编译、安装、跑测试）**：用 **`exec_task`（异步）**：
  1. `exec_task {"command":"npm run build"}` → 立即返回 `taskId`；
  2. 用 `get_task_result {"taskId":"..."}` 轮询（可先干别的，稍后再查）；
  3. 用 `list_tasks` 查看自己所有任务，防止遗忘；
- 异步任务**不怕 Agent 掉线**：任务在客户端后台执行，结果保留约 15 分钟，重连后凭 taskId 可取。

## 5. 长任务中定期复查

任务较长时，**每执行 2~3 条命令后**再次调用 `get_client_messages`，检查用户是否在中途发来新指令。

## 6. 破坏性操作前确认

执行删除、覆盖、移动、格式化等破坏性命令**之前**，先调用 `get_client_messages`，确认没有与当前操作冲突的用户指令。

## 7. 任务队列机制说明

- 客户端 UI 底部有一个任务队列抽屉，显示待读取的消息，支持排序、编辑、删除；
- 你读取后，客户端会显示 `✅ Agent 已读取` 并清空对应任务；
- 如果你多次调用 `get_client_messages` 均返回 `没有新消息`，说明用户没有新指令，可以继续工作。

## 8. 兜底提醒

无论你在调用什么工具，如果工具返回内容里出现 `📬 [来自客户端的消息]` 提示，说明队列中有未读消息——**先调用 `get_client_messages` 读完，再继续当前操作**。

## 9. 配额与限制（避免撞墙）

服务器对每个用户有资源配额，超限会被拒绝：

- **调用频率（QPS）**：每秒工具调用有上限（默认 5 次）。密集连续调用会返回"调用过于频繁"——**适当放慢节奏**（正常操作远用不到上限）；
- **输出大小**：单次工具返回（命令输出）默认上限 5MB，超大输出会被拒——**大输出先写入文件，再用 read_file 分段读取**；
- **下载大小**：单次下载文件默认上限 5MB，大文件不适合用 `download`；
- **异步任务并发**：每设备同时最多 3 个任务在跑，超出会被拒——先等前面的完成或通过 `list_tasks` 查看。

## 10. 权限模式

客户端有两种权限，由用户在界面上设置：

- **工作区模式**（默认）：只能在默认工作区活动。`create_session` **不能自定义工作目录**（会被拒）——需要跨目录工作时，**告知用户切换到超级模式**，不要反复尝试；
- **超级模式**：用户手动开放的全权限（跨目录、任意命令）。这是用户给你的信任，请谨慎使用，破坏性操作前先检查用户消息。

## 11. 管理工具（一般用不到）

`create_user` / `list_users` / `delete_user` / `set_user_limit` / `get_user_limits` / `get_audit_log` 是管理员工具，需要管理员密钥认证，普通调用会被拒绝——不必尝试。
